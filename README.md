# Hospital-Lab-Data-Analysis-SQL
Analyzed multi-hospital lab results using SQL to identify testing volumes and data quality issues.
I analyzed a dataset of 1,500 medical lab results across three different hospitals. The goal was to assess data quality (missing values) and calculate accurate clinical averages.

🛠️ Tools Used
SQL (SQLite)
SQLiteOnline
Key Insights
1. Hospital Testing Volume
I calculated the total number of tests performed at each hospital to compare their workloads.

Hospital_A: 502 tests
Hospital_B: 479 tests
Hospital_C: 519 tests

2. Average Cholesterol (mg/dL)
After filtering out mixed units and missing values, the accurate average cholesterol level for patients measured in mg/dL is 202.03 mg/dL, which indicates a slightly elevated average across the patient base.
